# FitPlan Skill

**اللغات:** [English](README.md) | [中文](README.zh-CN.md) | [Español](README.es.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | العربية

FitPlan Skill هي مهارة ذكاء اصطناعي ومكتبة TypeScript مستقلة عن المنصة، تحول ملف المستخدم إلى أهداف مفهومة للسعرات الحرارية والمغذيات الكبرى، مع اقتراحات وجبات ولوحة تغذية HTML يمكن فتحها محليا.

يمكن استخدامها كمهارة لمساعد ذكاء اصطناعي عبر `SKILL.md`، أو كمكتبة TypeScript داخل تطبيق ويب أو أداة CLI أو بوت أو وكيل أو خدمة خلفية.

![FitPlan Skill dashboard preview](docs/images/dashboard-preview.png)

> FitPlan Skill نسخة MVP للتخطيط العام للتغذية واللياقة. لا تقدم تشخيصا طبيا أو علاجا أو وصفات علاجية.

## الميزات

- تحسب BMR باستخدام معادلة Mifflin-St Jeor.
- تقدر TDEE باستخدام معاملات النشاط PAL.
- تدعم أربعة أهداف: `cut` و `bulk` و `maintain` و `glucose_control`.
- توزع أهداف البروتين والدهون والكربوهيدرات تلقائيا.
- تنشئ خطة وجبات أولية اعتمادا على قاعدة أطعمة صينية مرفقة.
- توضح أساس وزن الطعام: نيء، مطبوخ، أو حسب بطاقة العبوة الغذائية.
- تعيد JSON منظما ليسهل استخدامه في التطبيقات والوكلاء.
- تعرض لوحة HTML محلية في ملف واحد، قابلة للاستخدام دون اتصال.

## البنية

تنقسم FitPlan Skill إلى ثلاث طبقات قابلة لإعادة الاستخدام:

| الطبقة | الملفات | الغرض |
| --- | --- | --- |
| تعليمات المهارة | `SKILL.md` | توجه مساعد الذكاء الاصطناعي في جمع البيانات والحساب وتخطيط الوجبات والإخراج. |
| محرك الحساب | `src/` | دوال TypeScript لحساب BMR وTDEE والمغذيات الكبرى وتوليد الوجبات. |
| طبقة العرض | `templates/` / `src/render/` | تنشئ لوحة HTML محلية جاهزة للمتصفح. |

## الاستخدام كمهارة ذكاء اصطناعي

ضع المستودع في مجلد Skills الخاص ببيئة التشغيل واجعل المساعد يقرأ `SKILL.md`. يمكن للمستخدم أن يطلب مثلا:

```text
أنشئ لي خطة وجبات للتنشيف. أنا رجل، عمري 30 سنة، طولي 175 سم، وزني 75 كغ، أتدرب 4 مرات أسبوعيا، ولا آكل لحم البقر.
```

تساعد المهارة في جمع ملف المستخدم، وحساب BMR وTDEE والسعرات والمغذيات الكبرى، وإنشاء خطة وجبات منظمة، وعرض لوحة HTML محلية عند الحاجة، وإضافة حدود واضحة للحالات السريرية أو الأعلى خطرا.

## الاستخدام كمكتبة TypeScript

```ts
import { createFitPlan, createFitPageHtml } from "fitplan-skill";

const input = {
  profile: {
    sex: "male",
    age: 30,
    heightCm: 175,
    weightKg: 75,
    activityLevel: "moderate",
    goal: "cut"
  }
} as const;

const plan = createFitPlan(input);
const html = createFitPageHtml(input);
```

تعيد `createFitPlan` ملف المستخدم بعد تنظيمه، وBMR، وTDEE، والسعرات المستهدفة، والمغذيات الكبرى، والوجبات، والملاحظات. أما `createFitPageHtml` فتعيد مستند HTML كاملا يتضمن الأنماط والبيانات ولا يعتمد على CDN.

## شكل الإدخال

```ts
type UserProfile = {
  sex: "male" | "female";
  age: number;
  heightCm: number;
  weightKg: number;
  activityLevel: "sedentary" | "light" | "moderate" | "high" | "athlete";
  goal: "cut" | "bulk" | "maintain" | "glucose_control";
};
```

تغطي مستويات النشاط نمطا قليل الحركة حتى التدريب عالي الحجم. وتشمل الأهداف خسارة الدهون، وزيادة الكتلة العضلية، والحفاظ على الوزن، والتخطيط الغذائي المراعي لسكر الدم.

## قاعدة الأطعمة ومنطق التغذية

توجد قاعدة الأطعمة المرفقة في `assets/foods_zh.json`. عند إضافة أطعمة جديدة، حافظ على الحقول `id` و `nameZh` و `category` و `basis` و `servingUnit` والقيم الغذائية لكل 100 غرام. يحدد الحقل `basis` معيار الوزن: `raw` للوزن النيء، و `cooked` للوزن بعد الطهي، و `packaged` لما هو مذكور على بطاقة العبوة.

الصيغ التفصيلية موثقة في [docs/nutrition-logic.md](docs/nutrition-logic.md). تعتمد الاستراتيجية الافتراضية على `TDEE * 0.8` للتنشيف، و `TDEE * 1.1` لزيادة الكتلة، و `TDEE * 1.0` للحفاظ، أما هدف مراعاة سكر الدم فيستخدم سعرات الحفاظ مع خفض معتدل لنسبة الكربوهيدرات.
